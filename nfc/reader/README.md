# 리더기 검증

ACR1552U 연결부터 태그 UID 읽기, Java 브리지 서명 생성, React 키오스크 전달, 백엔드 서명 검증 및 반납까지 검증한다.

UID를 직접 입력한 요청은 반납할 수 없다. 백엔드와 브리지는 동일한 `NFC_SCAN_SECRET` 및 `NFC_BRIDGE_ID` 설정을 사용하며, 브라우저에는 비밀값을 전달하지 않는다. 서버는 서명된 실제 스캔을 확인한 뒤 키오스크·물품·대여에 묶인 60초 유효·1회용 반납 티켓을 발급하며, 같은 서명 증명을 제시한 반납 확정에서 티켓을 소비한다.

테스트 결과에는 태그 종류, 리더기와 운영체제 환경, 인식 결과, 오류 문구를 기록한다. 실제 태그 UID는 필요한 경우에만 테스트용으로 기록한다.
