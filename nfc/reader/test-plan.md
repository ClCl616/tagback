# ACR1552U 키오스크 연동 테스트 계획

## 검증 항목

- Windows에서 리더기가 인식되는지
- 서로 다른 태그의 UID를 읽을 수 있는지
- 태그를 뗐다 다시 댔을 때 인식이 회복되는지
- Java 21 브리지가 UID를 읽어 키오스크 화면에 전달하는지
- 키오스크 화면이 UID로 백엔드 물품 조회 API를 호출하는지
- 조회된 물품 정보가 화면에 표시되는지
- 미등록 태그와 리더기 연결 끊김을 적절히 표시하는지
