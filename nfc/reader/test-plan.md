# ACR1552U 키오스크 연동 테스트 계획

## 검증 항목

- Windows에서 리더기가 인식되는지 확인한다.
- 서로 다른 태그의 UID를 읽는지 확인한다.
- 태그를 뗐다가 다시 댔을 때 인식이 회복되는지 확인한다.
- Java 21 브리지가 UID를 읽어 키오스크 화면에 전달하는지 확인한다.
- 키오스크 화면이 UID로 백엔드 물품 조회 API를 호출하는지 확인한다.
- 조회한 물품 정보를 화면에 표시하는지 확인한다.
- 미등록 태그와 리더기 연결 끊김을 적절히 표시하는지 확인한다.

## 결과 기록

각 항목의 테스트 날짜, 환경, 결과(성공/실패), 관찰 내용 및 재현 절차를 기록한다.
