## 시각 검수 및 수정

모바일 탐색(390px), 코드(320px), 키오스크 시작·코드·최종 확인(1280×900)의 캡처를 열어 점검했다. 키오스크 안내 글자와 터치 키패드를 확대하고 모바일 상세 일러스트의 확대 변형으로 발생한 가로 넘침을 수정했다. 고정 하단 내비게이션 때문에 전체 페이지 캡처 중간에 메뉴가 나타날 수 있으며, 실제 사용 화면에서는 뷰포트 하단에 고정된다.

장애 시뮬레이터 자체 조회가 다음 오류를 먼저 소비하는 문제를 발견해 설정 알림과 데이터 알림을 분리했다. 장애 적용 대상을 선택할 수 있게 했고 StrictMode의 조회 effect 재실행은 동일 promise를 재사용하도록 수정했다. 수정 후 해당 브라우저 테스트가 통과했다.

## 검증하지 못한 항목

- Notion 세 원문의 내용: 연결 도구에서 404/접근 불가. 대응표는 사용자가 메시지에 제공한 요구사항 기준이다.
- 실제 서버 저장, 서버 인증·인가, 실제 다중 기기 동시성, 운영 데이터베이스/네트워크 장애 복구.
- 실명·본인 확인 및 1인 1계정 보장.
- NFC 하드웨어 통신·브라우저 지원 범위·현장 설치 환경·실물 회수 감지.
- iOS/Android 실기기, Safari/Firefox, 실제 공용 터치 단말, 스크린리더의 별도 사용성 평가.

모의 저장·모의 NFC 성공을 실제 서버 또는 장비 연동 성공으로 보고하지 않는다. 서버 책임을 시연하는 클라이언트 로컬 구현이며 운영 배포 전 별도 연동·검증이 필요하다.
