# 관리자 물품 관리

## 물품 이미지

등록·수정 창에서 개별 물품 이미지를 선택·미리보기·교체·삭제할 수 있다. JPG/PNG/WEBP, 입력 최대 5MB를 지원하며 브라우저에서 실제 이미지 디코딩 후 긴 변 1024px 이하 JPEG로 변환한다. 저장 가능한 결과는 data URL 700,000자 이하로 제한한다. 변경은 저장 버튼을 눌러야 적용되며 취소하면 기존 이미지를 유지한다. 사용자 이미지가 없으면 기존 종류별 사진을 표시한다.

현재 이미지는 mock DB와 함께 해당 브라우저 localStorage에 저장된다. 서버 업로드나 다른 기기 동기화는 없으며, 저장 공간 부족 시 오류를 표시하고 입력을 유지한다. 실제 API 연결 시 파일 저장소와 서버 측 형식·크기 검증이 필요하다.

이미지 형식·손상·용량 거부, 미리보기, 저장 후 새로고침 유지, 삭제 취소/적용을 브라우저 테스트로 확인했다.

작업 브랜치: `feat/admin-item-management`. 기존 사용자 UI 브랜치의 구현을 기준으로 분리했다.

이미지 시안 반영: 상태별 요약, 사진 썸네일, 전체 결과 스크롤 목록, 상태 선택 필터, 선택 행 강조, 우측 물품 상세 패널을 제공한다. 상세 패널에서 수정·상태 변경 창으로 연결한다. 950px 이하에서는 상세를 목록 아래로 배치한다.

정밀 시안 반영: 사용자가 첨부한 `public/images/admin-reference.png`를 SVG viewBox로 필요한 사진 영역만 표시한다. 배경 전체를 화면으로 덮은 것이 아니라 목록·버튼·필터 등은 실제 HTML UI다. 시안의 프로필은 mock 운영자 '홍길동'이며 실제 인증 사용자 정보는 아니다. 대여 현황/점검·수리 메뉴는 각각 상태 목록 필터로 연결하고, 설정은 현재 대여소와 서버 연동 전 제한을 보여준다. 체크박스는 검색 결과 전체 선택, 목록 아이콘은 행 간격 전환으로 동작한다. 원본과 같은 1586×992 크기의 스크린샷으로 비교했고 390px 가로 넘침도 검증했다.

시안 반영 후 TypeScript·production 빌드 및 관리자 브라우저 테스트 4개 통과. 선택→상세→수정, 상태 필터와 스크롤 목록을 추가 검증했다.

개발 서버의 `/admin/items`에서 물품 검색, 카테고리/상태 필터, 상태별 수량, 개별 물품 등록 및 수정을 제공한다. 카테고리는 기존 카탈로그의 물품 분류에서 선택한다. 등록한 물품은 동일 origin의 모바일/키오스크와 mock DB를 공유한다.

- 등록: 이름, 관리번호, 카테고리, 대여소, NFC 인식 태그 ID, 상태. 등록은 실물 1개 단위다.
- 수정: 이름, 관리번호, 카테고리, 상태. 태그 교체와 대여소 이동은 별도 연동 범위다.
- 상태: 대여 가능, 대여 중, 점검 중, 수리 중. 대여 중은 대여 흐름으로만 설정하며 진행 중 대여가 있으면 종류/상태 변경을 거부한다.
- 중복 태그, 잘못된 입력, 오래된 편집본의 덮어쓰기를 adapter에서 거부한다. 저장 실패 시 입력을 유지하고, 취소 시 데이터를 변경하지 않는다.
- 기존 대여 이력 및 비활성 태그 상태를 보존한다. 비활성 태그를 상태 변경으로 재활성화하지 않는다.
- 삭제, 종류 관리, 태그 교체/하드웨어 등록, 관리자 로그인과 서버 인가는 후속 범위다.

실제 관리자 인증 API가 없는 동안 개발 모드에서만 라우트와 쓰기를 허용한다. production 빌드에는 관리자 라우트가 등록되지 않는다. 이것은 운영 권한 구현이 아니다. 실제 배포 전 ADMIN 서버 인가, CRUD 계약, 상태 변경 기록, NFC 등록 및 DB 트랜잭션을 연동해야 한다.

기존 PR #8은 수정하지 않는다. 이전에 요청한 PR 운영 규칙 문서의 로컬 변경도 보존한다.

- 모의 서비스 테스트 20개 통과.
- 관리자 테스트 3개를 포함한 브라우저 테스트 25개 통과.

## 관리자 입력 개선

이름과 관리번호를 별도 필드로 저장하고, 기존 번호 포함 label은 대여 이력 호환을 위해 유지한다. 기존 물품은 표시 시 번호를 분리한다. 관리자 표시는 홍길동이다.

신규 등록 창이 열려 있고 저장/이미지 처리 중이 아닐 때 shared/nfc의 인식 이벤트를 구독한다. 태그 ID는 읽기 전용이며 인식 시 자동 입력된다. 수정 중에는 기존 태그를 유지한다. 현재 어댑터는 tagback-nfc BroadcastChannel 시뮬레이터이며 실제 리더기 전송 방식은 미연결이다.

변경 후 관리자 브라우저 테스트 5개, 모의 서비스 테스트 20개, TypeScript와 빌드 통과.


## 카테고리와 물품명 분리

카테고리는 학습 용품/생활 용품/전자 기기 등 상위 분류이며 목록 필터와 보조 문구에 표시한다. 등록·수정에서는 카테고리 선택 후 해당 물품명을 선택한다. 새 물품명을 입력하면 동일 카테고리의 카탈로그에 물품 저장과 함께 추가되며 기존 물품/대여 연결은 유지된다. 사진 없는 신규 분류는 일반 물품 아이콘으로 표시한다.

목록 필터와 등록·수정 창의 카테고리 선택 목록에서 '+ 새 카테고리 추가'를 선택하면 이름 입력과 추가 버튼이 열린다. 추가는 즉시 mock DB에 저장되므로 물품 편집을 취소해도 남는다. 공백을 정리하고 대소문자를 무시해 중복을 방지하며, 이미 존재하는 이름은 기존 항목을 선택한다. 현재 저장 범위는 해당 브라우저이며 실제 서버 저장은 아니다.

## 목록 및 이미지 입력 정리

체크박스와 행 간격 전환 버튼을 제거했다. 새로고침은 아이콘만 중앙 정렬하고, 선택 화살표는 각 필터 오른쪽에 동일 간격으로 표시한다. 관리자 입력의 주황 포커스를 녹색 테두리로 대체하되 키보드 버튼 포커스는 유지한다.

이미지 영역의 선택 표시와 부가 설명은 제거했다. 신규 물품 이미지는 필수이며, 업로드 이미지를 삭제한 채 저장할 수 없다. 기존 기본 사진이 있는 네 가지 초기 물품은 해당 사진을 유지하며 편집할 수 있다. 이미지 교체 및 취소 기능은 유지한다.

## 행 작업 및 편집 UI

카테고리 추가·삭제는 등록/수정 창에서만 제공한다. 목록은 행 어디서나 상세를 선택하고 키보드 Enter/Space로도 선택할 수 있다. 마지막 열은 제목 없이 더보기 메뉴를 제공하며 수정/삭제를 선택한다. 삭제 확인 후 물품을 목록에서 제외하고 태그를 비활성화하지만 이력용 데이터는 보관한다. 대여 중 삭제와 오래된 편집본의 삭제를 차단한다. 카테고리는 물품 분류에 사용된 항목을 삭제하지 못하게 보호한다.

물품명은 직접 입력하고 상태는 텍스트 라디오 버튼으로 선택한다. PC는 이미지/입력란 2열, 모바일은 세로형과 하단 저장 버튼으로 구성한다. 이미지 카드는 파일 선택과 드롭을 지원하며 카드 자체가 미리보기다. 이미지 삭제 버튼은 아이콘과 소형 버튼으로 제공한다. 이미지 필수 검증은 유지한다.

검증: 관리자 브라우저 테스트 9개, 모의 서비스 테스트 20개 및 TypeScript/빌드 통과. PC/모바일 편집창 캡처 확인.

## 카테고리 입력형 목록

등록/수정창의 카테고리는 검색 가능한 텍스트+목록으로 변경했다. 목록 클릭 또는 방향키/Enter로 선택하고, 새 이름 입력 후 Enter로 즉시 저장한다. 별도 추가 항목/추가 버튼은 없다. 선택하지 않은 입력은 물품 저장 전에 확인하도록 입력 검증한다. 각 항목 오른쪽 − 버튼으로 삭제 확인창을 화면 중앙에 띄우고, 취소/삭제를 선택한다. 삭제는 기존 이용 이력 보호 규칙을 유지한다. 목록 필터는 조회 전용이다.

## 정렬 및 기본 이미지

물품명·관리번호·태그 ID·상태 제목 버튼은 기본 → 오름차순 → 내림차순 → 기본 순서로 전환한다. 문자열은 한국어 기준, 관리번호/태그의 숫자는 자연 정렬한다. 같은 값의 순서는 기존 순서를 유지하며 기본 상태로 돌아가면 원래 목록 순서를 복원한다.

업로드 이미지가 없는 목록/상세/편집창은 공통 박스 아이콘을 표시한다. 삭제 버튼은 업로드한 이미지가 있을 때만 업로드 카드 밖 하단에 표시한다. 신규 등록 이미지 필수 규칙은 유지한다.

## 파일 선택 취소와 목록 선택 해제

파일 입력의 cancel 이벤트와 dialog 자체의 cancel 이벤트를 구분하여 파일 선택 취소가 편집창을 닫지 않도록 수정했다. 파일 cancel 이벤트를 발생시켜 입력/미리보기 유지와 편집창 Escape 닫기를 확인했다. OS 파일 선택창 자체의 자동화가 아닌 브라우저 이벤트 회귀 검사다.

목록 행·상세 패널·열린 dialog 내부를 제외한 클릭은 선택 및 상세 패널을 해제한다. 검색/카테고리/상태 변경도 해제하며, 편집 취소 버튼처럼 클릭 중 사라지는 요소는 이벤트의 원래 경로로 판별하여 선택을 유지한다. 관련 회귀 테스트 2개 통과.

## 자동 동기화와 상세 패널 고정

같은 창의 tagback-change 및 같은 origin의 다른 탭 storage 변경, 창 재포커스 시 관리자 카탈로그를 자동 갱신한다. 백그라운드 갱신은 기존 목록을 지우지 않으며 요청 순서를 검사하여 오래된 응답의 덮어쓰기를 막는다. 실패하면 기존 데이터와 재시도 오류를 표시한다. 편집 중인 입력은 유지하며 서버 역할의 mock adapter 충돌 검사도 유지한다. 다른 기기 동기화는 실제 서버 연동 범위다.

등록/수정 완료 배너를 제거했다. 상세 패널은 항상 레이아웃에 남으며 선택 해제 상태에서는 물품 선택 안내를 표시한다. 상태 변경은 선택된 상세와 목록에 자동 반영된다.

## 두 단계 물품 / NFC 등록

신규 물품 생성과 NFC 연결을 분리하고, 미등록 물품의 후속 연결 및 부분 성공 재시도를 추가했다. 현재 구현은 개발용 mock이며 실제 서버 연결 전 계약 확인 사항과 검증 결과는 [admin-nfc-contract.md](admin-nfc-contract.md)를 따른다. 이전 단일 저장/수정 중 태그 고정 설명에서 태그 미등록 물품은 후속 연결 가능하도록 확장되었다.
