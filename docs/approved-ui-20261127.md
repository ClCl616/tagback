승인 시안의 샘플 사진/다중 이미지/제조사/모델/미지원 통계는 실제 데이터로 대체하거나 제외한다. 따라서 해당 영역의 정보량은 시안과 다르다. 서체는 로컬 설치된 Pretendard/Noto Sans KR/Malgun Gothic 순으로 폴백하며 승인 전용 폰트 바이너리는 제공되지 않았다. 로고는 기존 자산을 사용하며 승인 이미지의 잎 모양과 차이가 남는다. 관리자 물품 종류 집계와 개별 실물 업무가 함께 있어 AD-02와 표 밀도가 다르다. 이 차이를 완전 일치로 보고하지 않는다. 네이티브 장비 이미지·실물 NFC·운영 API는 검증 근거를 구분한다.

## 반영 내용

### 사용자 웹

- 인증된 홈 진입/새로고침/재로그인 시 이용 코드를 자동 갱신한다. 발급 버튼과 남은 시간은 표시하지 않는다.
- 서버의 현재 코드를 2초 간격 및 화면 복귀 시 확인한다. 만료와 대여·반납 완료 시 갱신하며, 다른 접속 화면도 다음 조회에 반영한다.
- 갱신된 이전 코드는 새 거래에 사용할 수 없다. 이미 확인한 거래는 독립된 180초 거래 인증 유효기간 내 계속할 수 있다. 거래 완료가 이전 코드로 발생하더라도 현재 코드 갱신을 보장한다.
- 개별 물품 카드에 이미지·이름·식별번호·상태를 표시한다. 전체/대여 가능 필터와 상세 조회를 제공하며 물품 선택·예약·대여 확정은 키오스크에서 한다. 태그 등록 대기는 공개 목록에서 제외한다.
- 기존 카카오 로그인과 가입을 유지하고 가입 후 목적지 이동 경쟁 조건을 수정했다.

### 관리자 웹과 계정

- 등록된 3자리 관리자 번호 + 개인 비밀번호로 웹/키오스크에 로그인한다. 대표 관리자 번호는 `000`이다.
- 최초 대표 계정은 기존 `tagback.admin.password-hash` 설정으로 생성한다. 비밀번호 원문은 소스·시안·문서에 포함하지 않는다. 이미 생성된 계정의 비밀번호는 설정 파일 변경으로 바뀌지 않는다.
- 대표 관리자만 일반 관리자 생성/비활성화와 접속 기록 조회를 한다. 번호·이름·접속 경로/시간을 표시한다. 일반 관리자는 자동 발급된 임시 비밀번호를 첫 로그인에서 변경해야 다른 기능을 이용할 수 있다.
- 개별 물품 카드 대시보드와 연체·점검/수리·태그 대기 현황을 제공한다. PC 상세는 오른쪽 패널, 좁은 화면/키오스크는 전체 화면이다.
- 개별 이미지 → 종류 대표 이미지 → 기본 아이콘 순서로 표시한다. 이미지 등록/변경/삭제를 제공한다. PNG/JPEG 입력 최대 2 MiB, 최대 2048×2048, PNG 재인코딩 후 최대 4 MiB이며 DB에 저장한다. 이미지 URL은 불변 UUID이고 미참조 데이터는 제거한다.
- 물품 상세/등록 흐름에서 태그를 연결한다. 웹에서는 비활성 안내, 키오스크에서는 실물 NFC 증명으로 활성화한다. 태그 없이 저장하면 등록 대기 상태다.
- 관리자 화면은 15초마다 갱신하되 편집/태그 등록 중에는 초안을 유지한다.

### 키오스크

- 큰 대여/반납 버튼, 정상 연결 표시 및 공개 관리자/연결 설정 버튼 제거.
- 연결 문제가 확인될 때만 우측 상단 경고를 표시한다. 클릭/터치/마우스 올림은 원인만 표시하고 복구 설정은 관리자 인증 뒤에 제공한다.
- 시작 화면 TagBack을 5초 안에 5회 누르면 관리자 인증으로 이동한다. 번호와 영문·숫자·기호 비밀번호를 받는다.
- 인증 후 딥그린 배경/아이보리 요소와 관리자 모드 문구를 표시한다. 웹과 동일한 데이터·메뉴·기능을 사용하고 터치 크기에 맞춘다.
- 관리자 5분 무조작 시 로그아웃한다. 저장/태그 등록 및 결과 확인이 필요한 작업 중에는 자동 복귀하지 않는다.
- 대여: 코드 → NFC → 물품 확인 → 확정. 반납: 코드 → NFC → 정상/손상 선택 → 확정. 반납 상태는 처음에 선택되지 않으며 손상 설명 입력은 없다.
- 한 번에 1개를 처리한다. 서버 저장 확인 후 완료를 표시하고 5초 뒤 자동 복귀하거나 ‘처음으로’를 누른다. 대여 완료에만 반납 예정 시각을 표시한다.
- 응답 유실 시 기존 작업 ID/증명을 재사용하여 결과를 확인한다. 관리자 재인증도 기존 태그 작업을 보존한다.
- 설치 앱에서 관리자 기능은 네이티브 허용 목록 통신을 사용한다. 인증 토큰은 렌더러에 직접 노출하지 않으며 이미지도 고정 경로로 읽는다.
