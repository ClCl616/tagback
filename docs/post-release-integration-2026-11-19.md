# 0.1.2 이후 통합 변경 — 2026-11-19

통합 기준은 원격 develop `cfdd5f7`이다. SMS 콘솔, 모바일 화면, 공통 관리자/태그, Windows 0.1.4 작업 폴더의 변경을 별도 `codex/post-release-integration` 브랜치로 모았다. 기존 작업 폴더의 미커밋 변경과 실행 중인 서비스는 보존한다.

## 포함 기능

- 임시 SMS: DB 커밋 후 API 콘솔에 마스킹 전화번호·용도·코드·만료를 출력한다. 챗봇 전환 전 임시 방식이며 실제 문자 전송이 아니다.
- 모바일: 767px 이하 헤더/메뉴 고정, 목록 내부 스크롤, VisualViewport와 키보드 높이 대응, 뒤로 가기 스크롤 복원, 중복 카드/여백 축소.
- 관리자: 사용자 ADMIN 역할과 분리한 공통 비밀번호, PBKDF2 해시, 웹/키오스크 세션 분리, 만료/폐기/로그인 제한. V21 마이그레이션 포함.
- 태그: 웹에서 TAG_PENDING 물품 등록, 키오스크에서 관리자 인증과 서명된 NFC 스캔으로 등록/교체. UID 직접 입력 API 차단, 대여 중 교체 금지, 상태 보존, 멱등 복구와 감사 기록.
- Windows 0.1.4: 연결/설정 화면, 관리자 설정 잠금, origin 한정 인증서 신뢰, 리더기 탐색/재시작, 비밀 없는 진단 내보내기, 선택형 자동 실행.
- 거래 복구: 서버 쓰기 전 DPAPI 암호화 journal 저장, 강제 종료 후 동일 요청 재확인. 서버 인증 만료 등 자동 확인 불가 시 관리자의 기록/실물 대조·재인증·명시 확인으로 운영을 재개하며 서버 거래를 임의 변경하지 않는다.

## 이전 배포 기록과 이 PR의 범위

로컬 기록상 11월 19일 모바일 및 공통 관리자 기능을 로컬 Compose와 chi-server에 반영하고 V21·HTTPS 로그인/로그아웃·보호 조회를 확인했다. 운영 서버는 Git checkout이 아닌 배포 폴더이며 운영 전용 도메인/Origin·DB 권한·개발 API 차단 설정을 보존했다. 이 PR의 compose.yaml은 기존 로컬 시험 구성이다. 운영 전용 설정이나 비밀 파일을 그대로 저장소에 옮기지 않는다.

Windows 0.1.4는 이 PC에 설치해 기존 설정/키 보존을 확인한 기록이 있다. 설치 파일·백업·진단 산출물·실제 비밀번호·인증서·DB dump는 커밋하지 않는다. 0.1.4 공개 Release 게시와 코드 서명은 이 PR에 포함하지 않는다.

## 검증 및 제한

통합본 재검증 결과: 웹/설치형 TypeScript·Vite 빌드 통과, 프론트 단위 43개·HTTP 화면 42개·브라우저 브리지 17개·설치형 화면 13개 통과. Windows 단위 20개, Java 리더기 17개 통과. 백엔드 전체 실행은 총 255개 중 142개 통과·113개 환경 조건으로 제외, 실패/오류 0이다. 별도 PostgreSQL 17 컨테이너 `tagback-pr-admin-test-20261119`에서 공통 관리자 통합 8개(전체 실행의 통과 수에 포함)를 확인했다. 운영 DB나 기존 서비스는 변경하지 않았다.

기존 패키지 smoke/upgrade-smoke와 설치 검증은 해당 작업 당시 기록이며 이번 통합에서 설치 앱이나 운영 서비스를 재배포하지 않는다. GitHub Actions 결과는 PR에서 별도로 확인한다.

실물 NFC 등록/교체/대여/반납, 다른 PC 설치, 실제 OS 로그인 자동 실행, 운영 DB 전체 거래는 미검증이다. Android는 보류, 자동 업데이트는 범위 밖이다. 대여의 서버 NFC 증명 강제, 만료 후 서버 거래 결과 조회, 관리자 대량 조회, 운영 인증/챗봇 전환 등은 별도 후속 작업이다. 공통 비밀번호 감사는 개인 식별이 아닌 세션·시각·리더기 기준이다.
