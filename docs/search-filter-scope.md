# 검색·필터 조회 범위

작성일: 2026-11-06. 10주차 검색·필터 조회 작업의 구현 기준이다.
이 문서는 목표와 구현 범위를 정리한다. 2026-11-06 기준 검색·필터 백엔드 API와 관리자 실제 서버 조회 화면을 구현했다. 모바일 화면의 실제 서버 연결은 아직 진행하지 않았다.
2단계 요청·응답과 권한 기준은 [검색·필터 조회 계약](item-api-contract.md#10주차-검색필터-조회-계약)에 정리했다.

## 대상과 기존 상태

- 관리자 물품 목록과 일반 사용자 모바일 물품 탐색을 대상으로 한다.
- 기본 mock 모드의 관리자 화면은 mock 카탈로그를 내려받아 물품명, 태그와 종류명을 검색하고 상위 카테고리와 상태를 필터링한다. HTTP 인증 모드에서는 서버 목록을 조회한다.
- 모바일은 현재 mock 카탈로그를 사용하여 물품 종류명과 상위 카테고리로 조회한다. 비회원도 탐색할 수 있다.
- 서버는 로그인 사용자 물품명·종류명 검색, 관리자 활성 태그 검색, 비회원 공개 카탈로그를 제공한다. HTTP 인증 모드의 관리자 화면은 관리자 목록 API에 연결한다.
- 화면의 상위 카테고리와 서버의 물품 종류는 다르다. 서버에는 상위 카테고리와 물품별 대여소가 없으므로 임의로 매핑하지 않는다.

## 관리자 목록

- 검색어는 물품명과 물품 종류명에 대해 앞뒤 공백 제거, 대소문자 구분 없는 부분 일치를 적용한다.
- 태그 검색은 현재 연결된 활성 태그만 대상으로 한다. 입력의 공백, 콜론, 하이픈을 제거하고 대문자로 변환한 뒤 부분 일치한다. 비활성 태그 이력은 검색 대상이 아니다.
- 종류 필터는 서버의 물품 종류 ID를 사용한다. 상위 카테고리 필터는 서버에 해당 데이터 모델이 없어 별도 확장이 필요하다.
- 상태는 TAG_PENDING(태그 연결 대기), AVAILABLE(대여 가능), RENTED(대여 중), INSPECTION(점검 중), REPAIR(수리 중)를 구분한다.
- 검색어, 종류, 상태는 AND로 결합하고, 검색 대상 필드들은 OR로 결합한다. 빈 검색어는 검색 조건을 적용하지 않는다. 태그 검색은 관리자 전용 목록에서만 지원한다.
- 서버 페이지네이션을 사용하며 조건 변경 시 첫 페이지로 이동한다. 기본 정렬과 정렬 UI의 서버 처리 범위는 API 설계에서 명시한다.

## 모바일 물품 탐색

- 비회원이 물품명과 종류를 검색하고 물품 종류 및 대여 가능 여부로 결과를 좁힐 수 있도록 한다.
- 공개 조회는 별도 응답과 권한 경계를 설계한다. 관리자용 개별 물품, 태그 UID 또는 이력을 비회원에게 노출하지 않는다.
- 사용자에게는 종류별 전체 수량과 대여 가능 수량을 제공한다. 대여 가능 수량은 실제 서버 상태를 기준으로 한다.
- 기존 화면의 상위 카테고리와 대여소는 서버에 대응 데이터가 없으므로 실제 조회에 임의 값으로 연결하지 않는다. 서버 모델 확장 또는 화면 변경이 필요하다.

## 구현 시 확인

- 관리자 API 계약: 검색 파라미터, 입력 길이 제한, 리터럴 검색, 페이지·정렬 및 상태별 수량의 기준.
- 공개 API 계약: 노출 필드, 종류별 집계와 상세 조회, 빈 결과 및 오류 처리.
- 화면 연동: 기존 mock CRUD와 서버 데이터가 섞이지 않도록 데이터 출처와 지원 범위를 구분한다.
- 검증: 단일·복합 조건, 대소문자·특수문자, 비활성 태그, 빈 결과, 페이지 변경, 인증 및 비회원 공개 범위를 확인한다.
