# 카카오 채널 운영 준비 확인

## 2026-11-23 추가 확인

- 채널 관리자 화면에서 커스텀 메뉴와 리스트 메뉴가 모두 OFF이고 등록된 자동응답 메시지가 0개임을 확인했다. 채팅 설정에는 첫인사와 부재중 메시지가 설정되어 있으며, 채팅 시간은 매일 09:00~18:00이다. 이 설정 확인만으로 첫 진입·부재중 등 모든 상황에서 챗봇 응답과 충돌하지 않는다고 판단하지 않는다.
- 실제 카카오톡과 격리 시험 환경에서 취소 코드와 5분 경과 만료 코드가 거부되고, 재발급된 코드가 인증되어 웹의 PIN 화면으로 넘어가는 것을 확인했다. 별도 브라우저 로그인 완료는 사용자 확인에 근거한다. 운영 환경 종단 검증은 아니다.
- 수정된 시험 웹 이미지를 다시 빌드해 적용한 후 실제 카카오톡 인증 성공과 웹의 PIN 화면 진입을 확인했다. 이 화면에서 인증을 취소하면 이전 성공 안내가 사라지는 것도 확인했다.
- 예비 담당자는 채널 등록 관리자 목록에서 매니저로, 챗봇 관리자 목록에서 정식 작업자로 확인했다. 담당자가 직접 접근 가능한지는 별도 확인이 필요하다.
- 운영 채널 인증 스킬은 임시 시험 터널을 사용한다. 터널이 중지되거나 재생성되면 해당 주소가 동작하지 않으므로 운영 서비스의 고정 주소로 취급하지 않는다.

확인일: 2026-11-19. 카카오 정책과 요금은 변경될 수 있으므로 운영 전 다시 확인한다.

## 채널과 자동응답

- TagBack 채널은 사용자 결정에 따라 공개·검색 허용이다. 관리자센터에서 두 설정이 켜진 것을 확인했다.
- 앞선 시험에서 채널 커스텀 메뉴와 리스트 메뉴는 OFF, 자동응답 메시지는 0건이었다. 실제 카카오톡으로 인증 스킬 응답을 확인했으나, 부재중·첫인사 등 모든 시간과 상황에 대한 충돌 시험은 끝나지 않았다. 채널의 메뉴·자동응답은 챗봇과 동시 사용이 제한된다. [카카오 채널 연결 가이드](https://kakaobusiness.gitbook.io/main/tool/chatbot/tutorial/make_chatbot/tutorial_1)
- 현재 폴백 블록은 다른 블록에 매칭되지 않는 발화도 인증 스킬로 전달한다. 서버는 10자리 코드 형식을 검증하지만 일반 대화가 인증 실패 안내를 받을 수 있다. 운영 전 시간대별 첫인사·부재중 메시지 및 일반 발화의 동작을 실제로 시험한다.

## 자격·요금·제한

- 사업자등록번호가 없어도 일반 채널을 개설할 수 있지만 사업자 미확인 안내가 표시된다. 비즈니스 채널 심사는 해당 조직의 자격 및 증빙을 따로 확인한다. [채널 만들기](https://kakaobusiness.gitbook.io/main/channel/start)
- 카카오는 2022년 챗봇 일반 상품 무료 전환을 발표했다. 이는 특정 부가 기능, 스킬 서버 운영비 또는 현재의 모든 상품이 무료라는 뜻이 아니다. [카카오 공지](https://www.kakaocorp.com/page/detail/9756)
- 카카오 가이드에 따르면 Event API 메시지 발송은 월렛과 유료 요금이 적용된다. 현재 인증 흐름은 사용자가 먼저 대화하고 스킬이 응답하는 방식이며 Event API 발송을 사용하지 않는다. [Event API 안내](https://kakaobusiness.gitbook.io/main/tool/chatbot/tutorial/make_chatbot/tutorial_3)
- 일반 스킬 응답 시간은 5초 제한으로 안내된다. 관리자 공지는 AI 챗봇 전환 시 스킬 쿼터 제한을 경고한다. 현재 TagBack에 적용되는 월·일별 요청량 제한이나 현행 일반 상품 요금표는 확인하지 못했다. 실제 상품·예상 트래픽을 명시해 카카오에 확인하고 서버·터널 비용도 별도로 산정한다. [스킬 안내](https://kakaobusiness.gitbook.io/main/tool/chatbot/skill_guide/make_skill), [콜백 가이드](https://kakaobusiness.gitbook.io/main/tool/chatbot/skill_guide/ai_chatbot_callback_guide)

## 봇 사용자 식별값

- 카카오 공식 스킬 문서는 `userRequest.user.id`가 특정 봇의 사용자 식별값이며 같은 사용자라도 봇이 다르면 값이 달라진다고 설명한다. [스킬 요청 형식](https://kakaobusiness.gitbook.io/main/tool/chatbot/skill_guide/answer_json_format)
- 2021년 카카오 데브톡 답변은 친구 관계를 끊고 다시 맺을 때 `botUserKey`가 새로 생성될 수 있다고 설명하면서 챗봇 담당 부서에 확인하도록 안내한다. 오래된 답변으로 현재의 모든 경우에 대한 보장은 아니다. [카카오 데브톡 답변](https://devtalk.kakao.com/t/botuserkey/115201)
- 장기 미사용, 차단·해제/재추가, 채널 변경, 봇 교체·재연결 시 동일성이 유지되는지는 미확인이다. 카카오 챗봇 고객센터에 현재 정책과 보장 범위, 키 이전 수단을 문의한다. 계정이 연결된 사용자의 키가 바뀌면 기존 계정을 찾지 못하거나 새 계정 가입으로 이어질 수 있다. 기존 키와 새 키를 안전하게 연결할 독립적인 근거가 없으므로 자동으로 동일인으로 취급하거나 기존 계정에 연결하지 않는다. 봇 교체 및 계정 복구 방침을 운영 전에 결정한다.
- 시험이 필요하면 전용 카카오 계정·격리 DB에서 각 변경 전후의 식별값을 비밀 비교값으로만 비교하고 원문을 채팅·로그·저장소에 남기지 않는다. 이 테스트만으로 장기적인 보장을 확정할 수 없다.
