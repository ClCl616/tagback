# TagBack

Vision-UP 2026-2 · 돌려조

NFC 태그로 공용물품을 식별하고 반출·반납, 이용 이력, 연체, 점검·수리 상태를 관리하는 서비스입니다.

## 서비스 소개

TagBack은 카카오톡 로그인으로 이용자를 인증하고, NFC 리더기가 연결된 키오스크에서 공용물품의 대여와 반납을 처리합니다.

사용자는 모바일 웹에서 물품 재고와 대여 이력을 확인하고, 관리자는 물품과 운영 현황을 관리합니다.

## 주요 기능

- **사용자:** 카카오톡 로그인·회원가입, 물품·재고 조회, 내 대여 현황과 이용 이력 확인
- **키오스크:** 이용자 확인, NFC 물품 조회, 대여·반납 확인과 기록
- **관리자:** 물품 등록과 관리, NFC 태그 연결·교체, 대여 현황 및 연체·점검·수리 관리

태그 인식과 대여 확정은 분리되어 있습니다. 사용자가 대여 또는 반납을 확인하고 서버에 저장이 완료되면 처리 결과를 표시합니다. 중복 대여·반납을 방지합니다.

## 구성

| 디렉터리 | 용도 | 기술/상태 |
|---|---|---|
| `frontend/` | 휴대폰·PC 사용자 웹, 관리자 웹, 공통 키오스크 화면 | React, TypeScript, Vite |
| `backend/` | 인증·물품·대여·태그 API | Spring Boot, PostgreSQL, Flyway |
| `kiosk/windows/` | Windows 키오스크 호스트 | Electron 기반 설치형 앱, 리더기 연결·설정·거래 복구 |
| `nfc/` | 리더기·키오스크 연동 | Java PC/SC·SSE 브리지, 서명 이벤트 연동 |
| `docs/` | 설계·결정·개발 기록 | 기능 명세, API 계약, 검증 및 팀 합의 기록 |

사용자는 카카오톡 로그인으로 가입하고 로그인합니다. 모바일 웹에서 물품과 재고를 살펴보고 본인의 대여 현황과 이용 이력을 확인할 수 있습니다.

관리자는 별도의 공통 비밀번호로 로그인해 물품과 대여 현황을 관리합니다. 물품은 관리자 웹에서 등록하고, NFC 태그 연결·교체는 리더기가 연결된 키오스크 관리자 모드에서 처리합니다.

프론트엔드 실행과 테스트는 [프론트엔드 안내](frontend/README.md), DB 설정은 [DB 설정 안내](docs/database-setup.md)를 참고하세요.

## 운영 및 검증 범위

TagBack은 휴대폰·PC 사용자 웹, 별도 관리자 웹, 설치형 키오스크와 외장 NFC 리더기로 구성됩니다.

Windows 키오스크 통합과 설치 검증 기록이 있습니다. 다른 PC 설치와 실물 리더기를 포함한 대여·반납 업무 검증은 남아 있습니다. Android는 보류 중이며, 스마트폰 직접 NFC 인식은 초기 계획으로 구분합니다.

## 협업

`develop → 작업 브랜치 → PR → CI·팀장 검토 → develop 병합`

- 최신 `develop`에서 `feat/`, `fix/`, `docs/`, `chore/` 브랜치를 만듭니다. 통합 검증을 마친 버전은 별도 PR로 `main`에 반영합니다.
- 하나의 PR에는 하나의 작업을 담고 변경 내용과 검증 결과를 작성합니다.
- `develop` 대상 PR은 팀장(치우)이 직접 승인·병합합니다. 검증 범위는 PR에 명시합니다.
- API·DB·태그 입력 규격은 관련 담당자와 먼저 합의합니다.
- 위 규칙은 팀 운영 규칙이며 GitHub 보호 설정의 적용을 의미하지 않습니다.

자세한 내용은 [기여 안내](CONTRIBUTING.md)를 확인하세요.

자동 빌드·테스트와 필수 검사 설정은 [CI 안내](docs/ci.md)를 참고하세요.
