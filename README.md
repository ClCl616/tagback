# TagBack

### NFC 기반 공용물품 대여·반납 관리 서비스

**Vision-UP 2026-2 · 돌려조**

TagBack은 공용물품의 대여와 반납을 쉽고 정확하게 관리하기 위한 서비스입니다.

사용자는 카카오톡 로그인 후 모바일 웹에서 물품 재고와 대여 현황을 확인합니다. 현장에서는 키오스크와 NFC 리더기를 이용해 물품을 대여하고 반납할 수 있습니다. 관리자는 물품, 태그, 대여 현황과 이용 이력을 관리합니다.

---

## 프로젝트 소개

공용물품을 수기로 관리하면 물품의 현재 위치와 대여 상태를 파악하기 어렵고, 반납 누락이나 기록 오류가 발생할 수 있습니다.

TagBack은 물품마다 연결된 NFC 태그를 통해 개별 물품을 식별하고, 대여·반납 처리 결과와 이용 이력을 서버에 기록합니다.

태그 인식과 거래 확정은 별도 단계로 처리합니다. 사용자가 내용을 확인하고 서버 저장이 완료되면 대여 또는 반납 결과를 표시합니다.

---

## 주요 기능

### 사용자 웹

- 카카오톡 로그인 및 회원가입
- 물품 검색과 종류별 재고 조회
- 키오스크 이용 코드 발급
- 내 대여 현황과 반납 예정 정보 확인
- 이용 이력 및 연체 현황 확인

### 키오스크

- 이용 코드로 사용자 확인
- NFC 태그로 물품 식별
- 대여·반납 내용 확인 및 처리
- 반납 물품의 정상·손상 상태 확인
- 처리 결과가 불명확한 거래의 확인과 복구

### 관리자

- 공통 관리자 비밀번호를 통한 관리자 로그인
- 물품 등록·수정·삭제 및 상태 관리
- 키오스크 관리자 모드에서 NFC 태그 연결·교체
- 사용자·대여 현황과 이용 이력 조회
- 연체·점검·수리 상태 확인

## 서비스 이용 흐름

### 물품 대여

1. 사용자가 카카오톡으로 로그인합니다.
2. 모바일 웹에서 물품 재고를 확인하고 키오스크 이용 코드를 발급받습니다.
3. 키오스크에서 이용자를 확인합니다.
4. 대여할 물품의 NFC 태그를 인식합니다.
5. 물품 정보를 확인하고 대여를 확정합니다.
6. 서버 저장이 완료되면 대여 결과를 표시합니다.

### 물품 반납

1. 키오스크에서 반납을 선택합니다.
2. 반납할 물품의 NFC 태그를 인식합니다.
3. 물품 상태와 반납 내용을 확인합니다.
4. 반납을 확정합니다.
5. 서버 저장이 완료되면 반납 결과를 표시합니다.

### 물품과 태그 등록

1. 관리자가 관리자 웹에서 물품을 등록합니다.
2. 신규 물품은 태그 등록 대기 상태로 저장됩니다.
3. 리더기가 연결된 키오스크에서 관리자 모드로 진입합니다.
4. 물품을 선택하고 NFC 태그를 인식합니다.
5. 물품과 태그 정보를 확인한 뒤 연결을 확정합니다.

## 시스템 구성

```text
사용자 모바일·PC 웹
        │
        │ 로그인 · 재고 조회 · 이용 코드 · 대여 이력
        ▼
    TagBack 서버 ◀──────── 관리자 웹
        ▲                  물품 · 사용자 · 대여 관리
        │
        │ 이용자 확인 · 대여 · 반납 · 태그 관리
        │
     키오스크
        │
        ▼
    NFC 리더기
```

TagBack 서버는 PostgreSQL에 물품, 태그, 사용자 및 대여 기록을 저장합니다.

## 검증 범위

프론트엔드 빌드와 화면 테스트, 백엔드 테스트, Windows 키오스크 시험 앱 및 리더기 브리지 테스트를 수행했습니다.

다만 테스트 환경과 실제 운영 환경의 검증 범위는 구분합니다.

- Windows 키오스크 통합과 설치 검증 기록이 있습니다.
- 다른 PC 설치와 실물 NFC 리더기를 포함한 전체 대여·반납 업무 검증은 별도로 필요합니다.
- Android 구현은 보류 중입니다.

## 협업 방식

```text
develop → 작업 브랜치 → PR → CI·팀장 검토 → develop 병합
```

- 최신 `develop`에서 기능 또는 수정 단위의 작업 브랜치를 생성합니다.
- PR에 변경 내용과 검증 결과, 남은 사항을 기록합니다.
- `develop` 대상 PR은 팀장 검토 후 병합합니다.
- 통합 검증을 마친 버전은 별도 PR을 통해 `main`에 반영합니다.
