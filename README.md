# TagBack

Vision-UP 2026-2 · 돌려조

NFC 태그로 공용물품을 식별하고 반출·반납, 이용 이력, 연체, 점검·수리 상태를 관리하는 서비스입니다.

## 개발 범위

- 사용자: 물품·대여소·재고 조회, 로그인, 내 대여 현황과 이력
- 현장: 사용자 인증, NFC 물품 조회, 대여·반납 확인과 기록
- 관리자: 물품·태그 등록, 대여 현황, 연체·점검·수리 관리

태그 인식과 대여 확정은 분리합니다. 서버 저장 성공 후 완료를 표시하며, 중복 대여·반납을 방지합니다.

## 구성

| 디렉터리 | 용도 | 기술/상태 |
|---|---|---|
| `frontend/` | 모바일 사용자·공용 키오스크 화면 | React + TypeScript + Vite, mock 서비스 체험 구현 |
| `backend/` | 인증·물품·대여·태그 API | Spring Boot·PostgreSQL·Flyway 초기 환경, 서비스 API 후속 구현 |
| `nfc/` | 리더기·키오스크 연동 | Java 브리지 폴더 구조·검증 계획, 실제 통신 미구현 |
| `docs/` | 설계·결정·개발 기록 | 팀 합의 사항 기록 |

프론트엔드 실행과 테스트는 [frontend/README.md](frontend/README.md)를 참고하세요. `/mobile`과 `/kiosk`는 독립된 UI입니다. API·NFC·회원가입 문자 인증은 mock이며 실제 서버·SMS·장비 연결은 추후 진행합니다. 현재 대여소는 공학관 1곳이고, 확장을 위해 선택 UI와 대여소 타입은 유지합니다. 백엔드 DB 환경은 [설정 안내](docs/database-setup.md)를 참고하세요. 관리자 기능은 별도 후속 범위입니다.

신청서는 스마트폰 NFC·모바일 웹 방식을 명시합니다. 외장 리더기·키오스크 방식과의 차이는 검증 결과와 변경 결정으로 기록합니다.

## 담당

| 담당 | 주요 영역 |
|---|---|
| 안치우 | 팀장, 일정, 프론트엔드, UI/UX, 기능 통합 |
| 유나경 | 백엔드, 인증·권한, 데이터베이스, 물품·대여 관리 |
| 윤종민 | NFC 연동, 태그 등록·물품 연결, 관련 API·예외 처리 |

## 협업

`develop → 작업 브랜치 → PR → CI·팀원 리뷰 → develop 병합`

- 최신 `develop`에서 `feat/`, `fix/`, `docs/`, `chore/` 브랜치를 만듭니다. 통합 검증을 마친 버전은 별도 PR로 `main`에 반영합니다.
- 하나의 PR에는 하나의 작업을 담고 변경 내용과 검증 결과를 작성합니다.
- 다른 팀원 1명의 승인과 해당 작업의 빌드·테스트 통과 후 병합합니다.
- API·DB·태그 입력 규격은 관련 담당자와 먼저 합의합니다.
- 위 규칙은 팀 운영 규칙이며 GitHub 보호 설정의 적용을 의미하지 않습니다.

자세한 내용은 [기여 안내](CONTRIBUTING.md)를 확인하세요.

자동 빌드·테스트와 필수 검사 설정은 [CI 안내](docs/ci.md)를 참고하세요.
