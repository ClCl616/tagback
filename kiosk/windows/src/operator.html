연결·설정

서버와 리더기를 확인하고, 이 기기의 설정을 관리하세요.

연결 상태

서버확인 전
NFC 리더기확인 중
서명 키확인 중

연결 검사를 누르면 인증서와 서버 응답을 함께 확인합니다.

관리자 확인

연결 상태는 누구나 확인할 수 있습니다. 설정 변경은 공통 관리자 비밀번호로 잠금을 해제하세요.

서버에 연결할 수 없는 경우 Windows 운영자가 앱을 종료하고 --configure 옵션으로 실행해 설정을 복구할 수 있습니다.

이전 거래 결과 확인 필요

앱이 종료되기 전에 결과를 확인하지 못했습니다. 새 거래는 잠시 중지됩니다.

자동 확인이 불가능한 경우
관리자 웹에서 아래 물품의 대여·반납 또는 태그 상태를 확인하세요. 이 기능은 서버 거래를 변경하지 않습니다.


기기 설정
저장하면 진행 중인 입력 화면을 초기화하고 변경 사항을 적용합니다. 기존 키는 새 값을 입력하지 않으면 유지합니다.
키는 이 Windows 사용자 계정으로 암호화해 저장합니다. 관리자 로그인 비밀번호와 다른 값입니다.
앱 전용 추가 인증서
기본 인증서 저장소 사용 · 운영 주소는 보통 추가 등록이 필요 없습니다.
자체 서명 서버일 때만 관리자가 제공한 .crt / .pem 파일을 선택하세요. OS 전체 신뢰 설정은 바뀌지 않습니다.


F1 도움말 · Ctrl+Shift+S 연결·설정 · F11 전체화면 · 창을 닫으면 키오스크로 돌아갑니다.
