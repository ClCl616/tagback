# 확정 서비스 요구사항
TagBack은 NFC 기반 무인 셀프 대여·반납 SaaS. 대학에서 시작하되 기업·연구기관·공공기관에서도 사용할 범용 UI. 한국어, 라이트 모드. 사용자 웹(설치 불필요), 관리자 웹(독립 주소, 서버 권한 검증), Windows 키오스크(1920×1080 가로형)는 공통 서버와 DB를 사용하되 별개 인터페이스로 유지한다.

## 사용자 웹
카카오계정 간편 로그인만 지원. 별도 가입 폼, 이메일/비밀번호 로그인 없음. 최초 로그인 추가 정보 여부는 기존 구현에 따름. 물품/재고 조회, 상세, 통합 이용 코드 발급, 본인 대여 현황 및 이용 이력. 관리자 메뉴 미노출.

## 관리자
운영 현황, 물품 CRUD, NFC 연결, 재고와 물품 상태, 사용자, 대여·반납, 연체, 이용 이력 관리. 물품 종류와 개별 실물 구분. 개인정보 및 기능 접근은 기존 권한과 수집 범위 준수. 수동 사용자 등록, 관리자 강제 반납, 내보내기 등 확인되지 않은 기능 추가 금지.

## 이용 코드
대여·반납 공통 통합 코드이며 특정 물품에 종속되지 않고 매번 변경된다. 현재 유효한 코드를 사용한다. 자릿수, 문자 종류, 갱신 시점, 유효시간, 일회 사용 여부, 재발급 여부는 기존 서버 정책 확인. 이전 대여 코드를 요구하지 않는다. QR 방식 임의 추가 금지.

## 거래 흐름 (순서 변경 금지)
대여: 사용자 웹 조회 → 이용 코드 발급 → 키오스크 대여 시작 → 코드 입력/검증 → NFC 태그 인식 → 물품 식별/확인 → 대여 확정 → 서버 저장 성공 확인 → 완료.

반납: 키오스크 반납 시작 → NFC 태그 인식 → 물품 식별 → 물품 상태 입력 → 현재 통합 이용 코드 확인 → 반납 정보 확인 → 반납 확정 → 서버 저장 성공 확인 → 완료.

코드 확인 및 태그 인식만으로 재고 변경 또는 거래 완료 금지. 확정 중 중복 조작 차단. 요청 후 결과 불명확 시 기존 거래 상태 확인 또는 관리자 확인; 무조건 재전송 금지. 실제 서버의 안전한 재시도 방식 확인. 완료/취소 후 이전 사용자 정보 초기화(불명확 거래는 안전하게 해결 후). 결제, 예약, 온라인 반납, QR 인증, 자동 독촉, 즐겨찾기 등 미확정 기능 추가 금지.
