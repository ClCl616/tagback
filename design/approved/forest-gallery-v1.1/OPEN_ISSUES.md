# 미확정 사항 및 검증 항목
- 기술 스택, 기존 에이전트 지침, 디자인 토큰/컴포넌트, 라우트 및 권한.
- 카카오 로그인 실제 최초 인증 흐름, 추가 프로필 입력, 관리자 인증 방식 및 공식 버튼 리소스.
- 통합 코드 길이/문자 종류/갱신 시점/만료/일회성/재발급/검증 로직.
- 물품 이미지 지원 및 업로드 방식/형식/용량, 실제 상세 필드와 분류/정렬.
- 물품 종류와 개별 실물 데이터 관계, 태그 연결 방식, 실제 물품 상태 enum, 재고 변경 규칙.
- 반납 기한 정책, 연체 계산 기준, 시간대와 서버 시각, 거래 상태 및 집계 정의.
- 관리자 권한 및 수집 개인정보, 기존 내보내기/일괄 처리/직접 반납 지원 여부.
- NFC 리더기 모델/실제 인식 위치, Windows 디스플레이 배율/터치 하드웨어.
- 거래 결과 조회 가능 여부, 안전한 재시도/중복 방지, 세션 초기화/자동 복귀 정책.
- 최종 로고 벡터 원본 및 폰트 적용/라이선스.
- AD-05 개별 실물 화면은 명세 우선(이미지는 종류별 요약). 별도 수정 화면/모달/세부 상태는 명세 기반, 이미지 미제작.
- 실제 프로젝트를 읽거나 실행하지 않았으므로 기능, 접근성, 반응형, API 및 NFC 동작은 미검증.
