# Codex 실행 프롬프트
현재 TagBack 프로젝트의 UI/UX를 승인된 Forest Gallery V3 및 Design System v1.1을 기준으로 전면 리디자인해줘.

먼저 이 전달 패키지의 README.md, SERVICE_REQUIREMENTS.md, DESIGN_SYSTEM.md, DESIGN_TOKENS.json, IMPLEMENTATION_GUIDE.md, OPEN_ISSUES.md, QA_CHECKLIST.md, specifications/ 전체, design-images/IMAGE_INDEX.md를 확인하고 화면별 참조 이미지를 읽어줘. 프로젝트 내 AI 에이전트 개발 지침과 관련 UI/UX 문서도 모두 확인하고 적용 가능한 개발 규칙을 준수해줘.

기존 기능, 인증, 서버 API, 데이터 모델 및 권한 구조를 분석하고 보존해줘. 기존 디자인 시스템/공통 컴포넌트는 재사용 가능한 범위에서 활용하되 기존 UI의 시각적 형태에 얽매이지 말고 승인된 디자인으로 개편해줘. 기능 요구사항과 명세가 이미지보다 우선하며 이미지에서 발견된 잘못된 문구/기능/데이터/장식을 그대로 구현하지 마. 미확정 사항을 임의로 서비스 정책으로 결정하지 말고 기존 구현을 확인해. 보안·데이터 계약 변경이 필요하면 근거와 영향 범위를 보고해줘.

공통 토큰과 컴포넌트 → 사용자 웹 PC/모바일 → 관리자 웹 → Windows 키오스크 순으로 적용해줘. 사용자 웹은 카카오계정 간편 로그인만 지원하며 별도 가입 폼을 추가하지 마. 이용 코드는 물품에 종속되지 않는 매번 변경되는 대여·반납 통합 코드야. 대여/반납 단계 순서를 유지하고 서버 저장 성공 이후만 완료 화면을 표시해. 결과 불명확 시 중복 거래를 방지해. 키오스크는 1920×1080 가로형 독립 UI로 제작해.

각 인터페이스를 구현한 이후 실제 실행 화면을 확인하고 QA_CHECKLIST.md를 기반으로 검수해. 불필요한 문구, 어색한 배치, 비정상 간격, 반응형 오류, 디자인 불일치 등을 발견하면 작업 범위 내 직접 수정 후 재검수해. 실제 렌더링 및 테스트 없이 완료라고 판단하지 마. 환경상 실행할 수 없는 검증은 명확히 기록해. 작업 결과에는 변경 사항, 변경 파일, 검증 방법/결과, 미확정 사항 및 제한을 포함해줘.
