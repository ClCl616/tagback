# UI 구현 품질 검수 체크리스트
실제 검증 전 체크 금지. 실패/미검증은 근거와 재현 절차 기록.

## 시각적 품질
- [ ] 승인 브랜드 색상 및 디자인 토큰
- [ ] 공통 컴포넌트 재사용
- [ ] 불필요 문구 및 장식 제거
- [ ] 간격·크기·정렬 일관성
- [ ] 상태 색상 및 한국어 용어 통일

## 사용자 웹
- [ ] PC 및 모바일 실제 렌더링
- [ ] 긴 물품명 및 이미지 누락
- [ ] 검색/필터/결과 수량 일치
- [ ] 카카오계정 로그인 전용
- [ ] 통합 이용 코드 정책 및 PC/모바일 일치

## 관리자 웹
- [ ] 서버 관리자 권한 검증
- [ ] 종류/실물 구분
- [ ] NFC 연결 상태 일치
- [ ] 검색/필터/정렬/페이지 이동
- [ ] 통계 및 연체 집계 정확성

## 키오스크
- [ ] 1920×1080 및 DPI 실제 렌더링
- [ ] 터치 영역 및 버튼 간격
- [ ] 대여/반납 순서 유지
- [ ] 코드 및 NFC 오류 처리
- [ ] 서버 저장 성공 후에만 완료
- [ ] 중복 거래 및 반복 입력 방지
- [ ] 완료/안전한 취소 후 사용자 정보 초기화

## 공통 예외 및 접근성
- [ ] 로딩/빈 데이터/오류
- [ ] 키보드/포커스/레이블
- [ ] 텍스트 및 UI 대비
- [ ] 긴 텍스트 및 비정상 데이터
- [ ] 수정 후 재렌더링 및 재검수
