# TagBack Design System v1.1
Forest Gallery V3 기반. 색상 및 수치는 생성 이미지 측정값이 아닌 승인된 구현 권장값. DESIGN_TOKENS.json을 공통 값 참조로 사용하고 실제 기술 스택에 맞춰 변환한다.

## 브랜드/색상
포레스트 그린 #194D36, 밝은 중립 배경 #F7F8F5, 흰 표면 #FFFFFF, 텍스트 #202923, 테두리 #DFE4DE. 활성 메뉴 및 주요 행동에 브랜드 사용. 카테고리는 중립색. 관리자 사이드바 #103D2D, 활성 #30654E, hover #245440. 카카오 버튼은 공식 리소스 및 #FEE500 색상 예외. 로고는 승인 이미지 형태 참고, 기존 원본 확인 필요.

| 상태 | 텍스트 | 배경 | 의미 |
|---|---|---|---|
| 성공 | #17633A | #E6F3E9 | 대여 가능, 반납 완료, 정상, 연결 완료 |
| 정보 | #245A91 | #E8F0FA | 대여 중, 처리 중 |
| 주의 | #8A510C | #FFF3DD | 점검 필요, 지연 반납, 미연결 |
| 오류 | #B42318 | #FDECEA | 대여 불가, 연체, 파손, 실패 |
| 중립 | #56635B | #EDF0ED | 분류, 기타 중립 상태 |

실제 상태값을 우선하며 예시 상태를 DB에 추가하지 않는다. 상태는 색상과 문구/아이콘을 함께 사용한다.

단위 px(웹은 CSS px, 키오스크는 실제 배율 검증). 키오스크 줄 간격 1.4 권장. 코드와 수량은 tabular 숫자 권장.

## 간격/형태
4/8/12/16/20/24/32/40/48/64px. 카드 내부 PC 16, 모바일 12, 관리자 16~24, 키오스크 32. 카드 간격 16/12/16/24. 모서리 배지 4, 작은 버튼 6, 일반 입력/버튼 8, 카드 12, 모달 16, 키오스크 12~16. 일반 카드 그림자 없음, 드롭다운/모달만 토큰의 shadow 사용. 테두리 1px, focus 2px + offset 2px. 의미 없는 장식/그라데이션 제거.

## 컴포넌트
- 버튼: primary/secondary/tertiary/destructive, 기본/hover/pressed/focus/disabled/loading. small 32px, 기본 40, 주요 48, 키오스크 80. 모바일 터치 영역 최소 44×44, 키오스크 64×64 권장. 버튼 아이콘 16~20, 키오스크 32~48. 주요 행동은 한 영역에서 명확하게. 실제 서버 응답까지 중복 요청 차단.
- 입력: 44px 기본, PC 검색 48px, 좌우 12~16px, 접근성 레이블, 오류 메시지 하단. 검색/필터/정렬과 결과 수량 일치.
- 카드: PC 최소 너비 248px 권장, 이미지 4:3 contain, 누락 시 대체 아이콘, 이름 최대 2줄 및 전체 이름 접근 가능, 분류 중립, 대여 가능/전체 수량, 상세 보기. 대여 불가도 상세 확인 가능.
- 테이블: 헤더 44px, 행 52px(고밀도 44), 셀 좌우 16, 헤더 13/600, 데이터 14/400, 1px 구분선, hover #F0F2EE, 선택 #E5EEE7. 검색/필터 상단, 페이지 이동 하단. 수량 적을 때 불필요한 높이 고정 금지.
- 모달: 확인 400~440px, 폼 560px, 복합 최대 720px, 내부 24px, radius 16, 오버레이 검정 40%. 위험 작업 명확한 확인. 포커스 이동/복원, Esc는 안전한 상태에서만.
- 아이콘: Lucide 또는 기존 적합 라이브러리, 선형 2px, 일반 20/내비 24, 키오스크 32~48, 결과 64~80. 이용 코드는 티켓 아이콘, QR 제외.
- 예외 상태: 스켈레톤, 빈 데이터, 검색 결과 없음(필터 초기화), 입력 오류, 연결 오류(안전한 재시도), 처리 중, 완료, 결과 불명확. 색상만으로 의미 전달 금지.

## 레이아웃
PC 1440×900: 헤더 72, 콘텐츠 최대 1600, 좌우/상단 32, 필터 240+간격 24, 카드 4열 gap16. 모바일 390×844: 헤더 56, 좌우16, 2열 gap12, 하단 64+safe area. 하단 메뉴 물품 조회/내 대여 현황/이용 이력만. 로그인 전 메뉴 없음. OS 상태바/기기 외곽 구현 금지.
관리자 1440×900: 사이드바 232, 메뉴 44/간격4/좌우12, 헤더64, 여백32, 섹션24. 테이블 가용 너비. 관리자 사이드바 순서: 운영 현황, 물품 관리, NFC 태그 관리, 재고 관리, 사용자 관리, 대여·반납 관리, 연체 관리, 이용 이력. 기존 메뉴 구조와 권한 확인 후 적용.
키오스크 1920×1080: 헤더96, 안전 여백64, 콘텐츠 최대1440, 주요 버튼80, 상태 선택96 이상, 키패드96×88 이상, 간격24~32. 이전 좌측/주요 행동 중앙/취소 우측; 완료는 처음으로만. 실제 거래 결과 불명확 시 위험한 이동 제한. 단계 표시 실제 진행 상태와 일치. 대여/반납 초기 버튼 동일 강조 및 크기(560×360 권장, 간격32).

## 반응형
320~359 1열, 360~767 2열/하단 메뉴, 768~1023 최대3열/상단 메뉴, 1024~1279 최대3열, 1280~1599 최대4열, 1600 이상 최대5열. 실제 가용 너비 기준 열 감소. 좁은 화면에서 PC 필터 패널을 접거나 별도 필터로 전환. 1600 콘텐츠 최대 너비에서는 5열 최소 너비 충족 여부 검증. 가로 오버플로 방지. 키오스크 Windows DPI 확인.

## 접근성 및 문구
WCAG 2.2 AA 목표(검증 전 충족 주장 금지), 일반 텍스트 4.5:1, 큰 텍스트 및 의미 있는 UI 경계 3:1 목표. 키보드/포커스/레이블/모달/확대/모션 감소 설정 점검. 한국어 통일: 물품 조회, 이용 코드 발급, 내 대여 현황, 이용 이력, 대여 가능/불가, 반납 기한, 대여 확정, 반납 확정, NFC 태그 인식. 제목과 설명 반복 금지.
